Motion quality

Shopify Editions benchmark
  • Sambando / weightless driftFiguras com sway contínuo em RAF: translateY sin(time×0.6)×8px + rotate sin(time×0.4)×1.5deg. Independente do scroll.
  • Screen time generosoParallax em 150vh. Se o usuário passa em <6–7s, está rápido demais.
  • Weighted scrollLenis global com lerp ~0.08. Scroll é a timeline.
  • Burst no touchFlash branco → bloom radial → 80–120 sparks canvas → rays SVG. Cores [#fff, #fff8d6, #ffd460]. ~600ms.
  • Parallax em camadasBG 0.85× · mid 1.0× · FG 1.15×. Cloud layers L1→L5 com scale crescente.
  • Reduced motionFrame estático final. Sem canvas, sway ou parallax. Sec. 02 colapsa para ~100vh.

Do's and Don'ts

uso de marca
  • 01CTA Healing usa green. #BCF66B com texto #121212. Reading usa ink bg + paper text.
  • 02Duas portas, duas linguagens. Sec. 03 (lilac/geometric) e 04 (ink/organic) devem sentir radicalmente diferentes.
  • 03Sem sombras de marca. Use bordas 1.5–2px solid ink. Sombra só no floating CTA hover se necessário.
  • 04Motion ≠ Shopify visuals. Copie a craftsmanship (sambando, burst, screen time), nunca a art direction deles.
  • 0590% paleta restrita. ink + paper + lilac + green/purple. Pinks/teals só em editorial.
  • 06prefers-reduced-motion. Sempre forneça estados estáticos finais para parallax e loops.

Agent prompt guide

Build the Cosmic Pet Club home (Street × Soul). Use ds-galact.html :root tokens only — no raw hex. Brand: --purple, --lilac, --green, --ink, --paper; surfaces: --bg, --fg, --muted, --line; CTAs: --cta-reading-* (ink/paper), --cta-healing-* (green/ink). Typography: --font-display (Montserrat 800–900 uppercase Hero/H1/H2), --font-body (DM Sans UI/body), --font-editorial (Cormorant italic quotes), --text-display through --text-quote, --leading-* and --stack-* for rhythm. Spacing: --space-1…10 (4px base), --container-pad, --section-pad-y. Radius/borders: --radius-pill, --radius-card, --border-width 1.5px, --shadow none. Motion: --duration 220ms, --duration-reveal 640ms, --ease-notif; respect prefers-reduced-motion. Hero: .gx-hero-spline + Spline iframe interactivecubes-41qMxl12Iae6iphDwICaSs2p.
