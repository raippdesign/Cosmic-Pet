# Scroll Experience

## Objetivo

Criar uma experiência de scroll cinematográfica, clara e legível para o Cosmic Patch.

## Quando usar

Use para planejar ou implementar fluxo de página com sections em 100vh, pausas de leitura, parallax, transições, sticky content e narrativa visual.

## Princípio principal

O scroll deve guiar a narrativa. O efeito visual não pode competir com a mensagem.

## Regras obrigatórias

- Cada section deve ter uma função clara.
- Sections de leitura precisam de respiro.
- Animações devem ter começo, meio e fim.
- Não prender o usuário sem necessidade.
- Evitar excesso de pinning.
- Mobile deve priorizar clareza e performance.
- O conteúdo principal deve continuar acessível sem animação.

## Tipos de section

- Hero impactante.
- Manifesto curto.
- Preview de oferta.
- Section com pin.
- Section parallax.
- Cards sequenciais.
- Quote de pausa.
- CTA de decisão.

## Checklist

- Existe uma narrativa clara?
- O usuário consegue ler sem pressa?
- O scroll parece fluido?
- O mobile tem versão adequada?
- Existe fallback para redução de movimento?
- A performance continua boa?

## Prompt base

Planeje ou implemente esta experiência de scroll como uma narrativa visual para o Cosmic Patch. Defina o papel de cada section, onde haverá pausa de leitura, onde haverá pin, onde haverá parallax e como isso se adapta ao mobile. Priorize clareza, fluidez e performance.
