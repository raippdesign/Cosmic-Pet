# UI UX Review

## Objetivo

Revisar a interface do Cosmic Patch como designer de produto, considerando clareza, conversão, usabilidade, acessibilidade e consistência visual.

## Quando usar

Use após criar uma section, componente, página ou fluxo, antes do polimento final.

## O que revisar

- Clareza da mensagem.
- Hierarquia visual.
- Contraste.
- Leitura.
- CTA.
- Espaçamento.
- Alinhamento.
- Consistência com Design System.
- Estados interativos.
- Responsividade.
- Acessibilidade.
- Fricção na jornada.
- Conversão.

## Regras obrigatórias

- Não revisar apenas estética.
- Apontar problemas concretos.
- Separar problema de sugestão.
- Priorizar o que mais impacta o usuário.
- Não propor mudanças que quebrem a identidade do Cosmic Patch.

## Escala de prioridade

- P0: Quebra uso, leitura, acessibilidade ou conversão.
- P1: Prejudica clareza, hierarquia ou responsividade.
- P2: Melhoria visual ou refinamento.
- P3: Preferência estética opcional.

## Saída esperada

1. Diagnóstico geral.
2. Problemas por prioridade.
3. Recomendações práticas.
4. Ajustes de copy se necessário.
5. Checklist final.

## Prompt base

Revise esta interface como Product Designer especialista em UI, UX e Design System. Avalie clareza, hierarquia, espaçamento, contraste, CTA, acessibilidade, responsividade e consistência com o Cosmic Patch. Classifique problemas por prioridade e sugira ajustes práticos.
