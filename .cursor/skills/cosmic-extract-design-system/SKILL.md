# Extract Design System

## Objetivo

Extrair, organizar ou revisar os fundamentos visuais do Design System do Cosmic Patch.

## Quando usar

Use quando eu enviar HTML, CSS, Figma, prints ou código existente e pedir para entender ou padronizar o Design System.

## O que extrair

- Cores primárias.
- Cores secundárias.
- Cores de fundo.
- Cores de texto.
- Tokens de espaçamento.
- Escala tipográfica.
- Fontes.
- Pesos.
- Line-height.
- Letter-spacing.
- Radius.
- Shadows.
- Borders.
- Botões.
- Cards.
- Inputs.
- Estados interativos.
- Breakpoints.
- Padrões de section.

## Regras obrigatórias

- Não criar token duplicado.
- Não alterar tokens existentes sem justificar.
- Padronizar nomes de tokens.
- Separar tokens globais de estilos de componentes.
- Manter a escala simples e fácil de aplicar.
- Documentar exemplos de uso.

## Estrutura recomendada

- Foundations.
- Typography.
- Colors.
- Spacing.
- Radius.
- Motion.
- Components.
- Layout.
- Responsive rules.

## Prompt base

Analise o código ou material enviado e extraia o Design System atual do Cosmic Patch. Organize tokens de cor, tipografia, espaçamento, radius, sombras, motion, componentes e breakpoints. Aponte inconsistências, duplicações e melhorias sem alterar a identidade visual sem aprovação.
